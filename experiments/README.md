# Experiments

Each experiment gets a stable ID and its own directory:

`EXP-NNN-short-name/`

The experiment record should contain:

- hypothesis;
- exact proposed diff;
- target candidate version;
- what evidence would support or reject the change;
- candidate decklist;
- game log;
- final decision.

Experiment statuses are `planned`, `testing`, `adopted`, `revised`, or `rejected`.
